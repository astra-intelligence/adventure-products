# GitHub Repository Optimization Checklist

A practical checklist to make your GitHub repo discoverable, shareable, and credible.

## Social Preview
- [ ] 1280×640 social preview image uploaded in Settings → Social preview
- [ ] Image clearly shows project name and purpose
- [ ] Image reads well on both light and dark backgrounds
- [ ] Image under 1MB

## README
- [ ] Clear one-line description at the top
- [ ] "What is this?" / explanation section for newcomers
- [ ] Installation/getting started instructions
- [ ] Usage examples with code snippets
- [ ] Screenshots or GIFs of the project in action
- [ ] Badges (CI, license, version, stars)
- [ ] Contributing guide link
- [ ] License information

## Repository Settings
- [ ] Description filled in (under repo name)
- [ ] Website URL set (if applicable)
- [ ] Topics/tags added (up to 20)
- [ ] Social preview image uploaded
- [ ] Template repo setting (if applicable)

## Community Health
- [ ] CONTRIBUTING.md
- [ ] CODE_OF_CONDUCT.md
- [ ] SECURITY.md
- [ ] Issue templates configured
- [ ] Discussion category enabled (if applicable)

## SEO & Discovery
- [ ] Repository description contains relevant keywords
- [ ] Topics cover all relevant categories
- [ ] README includes a concise, keyword-rich first paragraph
- [ ] Social preview image has visible project name
