What is Web2MD?

          
Web2MD is a free online tool that converts any public web page into clean, readable Markdown. Paste a URL, get structured Markdown you can drop straight into a note, a README, a blog draft, or an AI prompt. No signup required for the free tier.

Frequently asked questions

          
Is Web2MD free?

          
Yes. The free tier gives you 10 conversions per day per IP address, with no account required. A one-time $1 license unlocks unlimited conversions, API access, and batch processing.


          
What pages can I convert?

          
Any publicly accessible web page. If the page is reachable and returns HTML, Web2MD can convert it to Markdown.


          
Does Web2MD work as an API?

          
Yes. The same engine behind the web tool is available as a simple HTTP API. Add your license key to the request to skip rate limits. See the API section above.


          
Is there an MCP server?

          
Yes — Web2MD is available as a Model Context Protocol (MCP) server, so AI assistants like Claude, Cursor, and other MCP clients can convert URLs to Markdown directly. It's listed in the official MCP registry as io.github.astra-intelligence/web2md.


          
What is Markdown?

          
Markdown is a lightweight markup language that uses plain-text formatting — like # for headings and **bold** for emphasis — to produce structured documents. It's the standard format for README files, notes, and AI-friendly text.


          
How does the free tier rate limit work?

          
The free tier allows 10 conversions per day per IP address, no account required. The daily counter resets automatically. If you hit the limit, wait for the next day or grab a one-time $1 license to unlock unlimited conversions — the license key is tied to you, not to your IP, so it works from any network.


          
Why is the converted Markdown missing images or ads?

          
Web2MD extracts the article's real content — headings, paragraphs, links, lists, and code blocks — and intentionally drops navigation, ads, and page chrome. Images are kept as links in the Markdown where the source page provides them. You get the readable core of the page, not a pixel-for-pixel copy of the layout.


          
Can I use Web2MD with an AI assistant or agent?

          
Yes, that's one of the main use cases. Feed the clean Markdown into an LLM for summarization, drafting, or research. For assistants that support Model Context Protocol (MCP), Web2MD is listed in the official MCP registry as io.github.astra-intelligence/web2md — Claude, Cursor, and other MCP clients can call it directly. Developers can also hit the REST API with a license key for programmatic use.


          
Can I convert pages that require login?

          
No. Web2MD can only convert pages that are publicly accessible without authentication. Pages behind a login, paywall, or bot challenge (like a CAPTCHA) cannot be fetched. This keeps the service simple, legal to use, and respectful of site access controls.


          
Does Web2MD store the pages I convert?

          
Converted content is returned to you and not permanently stored. Basic metadata (the URL, timestamp, and a rate-limit counter) is used so the service can enforce the free tier and protect against abuse. No account, email, or payment information is required for the free tier.


          
Can I convert a whole website or many URLs at once?

          
The web tool converts one URL at a time. For batch or automated workflows, use the REST API: pass each URL to /api/convert and include your license key to skip the free-tier rate limit. This is a common pattern for building documentation pipelines or feeding research corpora into an AI workflow.
