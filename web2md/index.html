FAQ

Is there a rate limit?

No hard rate limit for reasonable personal use. Please don't hammer the service with 1000s of requests per minute — it's hosted on a single VPS.

Can I use this in my open source project?

Yes. The API is free for open source and personal projects. For commercial batch usage, consider purchasing the CLI.

Does it handle JavaScript-rendered pages?

Web2MD uses server-side HTTP fetching (trafilatura + html2text), so it works best with static and server-rendered pages. Single-page apps may not render fully.

What about the CLI?

The CLI adds batch processing, file output, custom formatting, and license-gated file downloads. Available on Gumroad for $2.99.
